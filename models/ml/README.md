# Traditional Machine-Learning Baselines

This directory implements the non-neural baselines used on the 500-class iNaturalist subset:

- Local Binary Pattern (LBP) + Histogram of Oriented Gradients (HOG) with a
  linear SVM;
- LBP + HOG with a Random Forest (implemented but disabled in the default
  training entry point);
- SIFT Bag-of-Visual-Words (BoVW) with a linear SVM.

## Files

| File | Purpose |
| --- | --- |
| `data.py` | Validates class folders and loads train/validation/test paths and labels |
| `features.py` | Extracts grayscale LBP and HOG descriptors |
| `extract_features.py` | Writes LBP+HOG feature matrices for all splits |
| `train_lbp_hog.py` | Trains and evaluates the LBP+HOG SVM; also contains the Random Forest implementation |
| `bovw.py` | Extracts SIFT descriptors, builds the visual vocabulary, and forms histograms |
| `extract_bovw.py` | Fits the training vocabulary and writes BoVW features for all splits |
| `train_bovw.py` | Trains and evaluates the BoVW linear SVM |
| `test_bovw_robustness.py` | Applies five degradations in memory and evaluates the trained BoVW SVM |

## LBP + HOG workflow

Extract features:

```bash
python -m models.ml.extract_features
```

This resizes every image to `128 x 128`, concatenates a uniform LBP histogram with a HOG descriptor, and writes:

```text
models/ml/outputs/features/train_features.npz
models/ml/outputs/features/val_features.npz
models/ml/outputs/features/test_features.npz
```

Train and evaluate the default linear SVM:

```bash
python -m models.ml.train_lbp_hog
```

The SVM is an `SGDClassifier(loss="hinge")` inside a standard-scaling pipeline. The script reports validation and test top-1/top-5 accuracy and macro precision, recall, and F1.

`train_lbp_hog.py` also defines a 300-tree Random Forest. Its `run_experiment` call is commented out in `main()`; uncomment that block to reproduce the Random Forest experiment.

## SIFT + BoVW workflow

Build the 200-word visual vocabulary and extract split features:

```bash
python -m models.ml.extract_bovw
```

The vocabulary is fitted only on training SIFT descriptors. At most 200 keypoints are retained per image and at most 200,000 training descriptors are used for `MiniBatchKMeans`. The command writes the K-means model and the three feature matrices under `models/ml/outputs/`.

Train and evaluate the BoVW linear SVM:

```bash
python -m models.ml.train_bovw
```

Evaluate its robustness:

```bash
python -m models.ml.test_bovw_robustness
```

The robustness script applies Gaussian noise, Gaussian blur, motion blur, brightness reduction, and JPEG compression directly in memory at four severity levels. It does not consume the image copies generated by `utils/robustness.py`.

## Outputs

Generated artifacts are organized as follows:

```text
features/   # .npz feature matrices
models/     # fitted .joblib estimators and BoVW vocabulary
results/    # metrics, classification reports, and prediction arrays
```
